# HD2Runtime ModBuilder 1.3.0

Adds **throwable authoring** for HD2Runtime SDK 0.27.0 and makes ModBuilder find its own updates while it runs.

**Download:** `HD2Runtime-ModBuilder-v1.3.0-win-x64.zip` (Windows 10/11 x64). Extract it and run **`HD2RuntimeModBuilder.exe`**, or use **Install update** from any earlier version.

## Throwables
A new **Throwables** page (sidebar, right after Player Weapons) exposes HD2Runtime 0.27.0's `hd2.throwable` domain.

- **All 23 throwables:** every armory grenade, the K-2 Throwing Knife, the TM-1 Lure Mine and G/40-K Melta Mine, and the G/SH-39 Shield. Search and filter by the category and family HD2Runtime publishes.
- **388 editable fields** out of 411 published, grouped the way the game stores them:
  - **Inventory:** starting count, maximum count, and the amount received from supply.
  - **Detonation:** the fuse, where it is a real fuse.
  - **Explosion:** radii, shrapnel/bomblet count, and standard, durable and armor-piercing damage, demolition, stagger and push.
  - **Status effects** (fire, gas, gas confusion, stun): the strength applied per hit and the shared status duration.
  - **Shrapnel, bomblets and bomblet explosions** as their own sections.
  - **Throwing knife:** its direct-hit damage.
  - **Mines:** the deployed entity's health.
  - **Shield grenade:** the shield radius and health.
- **Read-only fields** show HD2Runtime's reason, for example the Dynamite's multi-setting fuse or the impact grenades' zero timer.
- **Shared data:** many values live in global settings rows. These show a **Shared · N** badge and a warning listing every throwable and other entity that uses them, and are written with `allow_shared`. A row reached through two throwables (for example the frag shrapnel shared by the G-6 Frag and TM-1 Lure Mine, or the fire status definition) is one value, so editing it through both is refused.
- **Unverified effects:** every throwable edit is written with `allow_unverified_effect`, and a warning says no changed throwable value has been confirmed in game yet. This is shown separately from the shared-data warning.
- **Generated mods** use `hd2.throwable(name)` with HD2Runtime's published accessors and typed field constants, for example `:explosion()`, `:shrapnel()`, `:explosion():status_effect('fire')`, `:bomblets():explosion()`, `:damage()` and `:shield()`. No raw addresses or IDs are written.
- Throwable edits appear on **Changes**, can be reset per field or per throwable, and can become in-game **Mod Options**.

## Automatic update checks
- ModBuilder checks for a new version **when it starts and every 10 minutes while it runs**. A new release shows the "HD2Runtime ModBuilder X is available" banner at the top of the window.
- Background checks never hide the banner, and a temporary network problem keeps the last result.
- A dismissed version stays hidden, and a newer release shows the banner again.

## Existing projects
- Projects open unchanged and stay pinned to their SDK. Rebinding a 0.26.0 project to 0.27.0 keeps every edit.
- A project that contains throwable edits is saved as project format 9. Older ModBuilder versions cannot open it, so update ModBuilder everywhere you edit that project. Other projects keep their format.

## Not exposed (no proven native owner in HD2Runtime 0.27.0)
The thermite's timed burn, the G-31 Arc's arc, the Pyrotech spray, the Melta Mine's flame wall, the smoke-cloud lifetime, the Seekers' seek radius, the Urchin's pulse count, throw speed and mine armor.
