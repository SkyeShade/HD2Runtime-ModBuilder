# HD2Runtime ModBuilder 1.4.1

A fix for **enemy and vehicle damage-zone edits**: editing one body part no longer blocks edits to the other parts.

**Download:** `HD2Runtime-ModBuilder-v1.4.1-win-x64.zip` (Windows 10/11 x64). Extract it and run **`HD2RuntimeModBuilder.exe`**, or use **Install update** from any earlier version.

**Requires [HD2Runtime 0.28.0](https://github.com/SkyeShade/HD2Runtime/releases/tag/v0.28.0)**, the same as 1.4.0.

## Fixes
- Fixed enemy and vehicle damage-zone edits being treated as shared values. After one edit, changing the same value on another part (for example a Charger's head and a leg plate, or two zones of one vehicle) was refused with "… is one shared value, already edited through …".
- Independent body parts and zones can now be edited together.
- Genuinely shared values are still detected and protected: an enemy attack row used by several attacks or enemies, a row shared by two throwables, or a row a Guard Dog and a vehicle mount both fire can still be edited through only one of them.

## Unchanged
- The project format, the bundled HD2Runtime 0.28.0 SDK and HD2Runtime behaviour are unchanged. Projects saved by 1.4.0 open as they are.
