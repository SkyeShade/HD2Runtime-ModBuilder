# HD2Runtime ModBuilder 1.0.1

A small naming and packaging cleanup. There are no authoring, SDK or generated-Lua changes.

**Download:** `HD2Runtime-ModBuilder-v1.0.1-win-x64.zip`. Extract it and run **`HD2RuntimeModBuilder.exe`**.

## Changes

- The application now ships as **`HD2RuntimeModBuilder.exe`** (`HD2RuntimeModBuilder.dll`, `HD2RuntimeModBuilder.Core.dll`, `HD2RuntimeModBuilder.runtimeconfig.json`, …) instead of the old internal `HD2RuntimeGUI.*` names.
- **Updating from 1.0.0 with Install update** works as before. The updater:
  - removes the old `HD2RuntimeGUI.*` application files and 1.0.0's browser cache folder;
  - installs the new files;
  - restarts the app as `HD2RuntimeModBuilder.exe`.
  - Other files in the folder are not touched.
- The ZIP also contains `HD2RuntimeGUI.exe`, an identical copy of `HD2RuntimeModBuilder.exe`. It exists only so that 1.0.0 can update itself; it starts the same app, and you can ignore or delete it.

## Unchanged

- Your projects, exports, SDK cache, imported game icons and settings stay in `%LOCALAPPDATA%\HD2RuntimeGUI\`. Nothing is migrated or rewritten, and existing projects open as before.
- Project format, SDK binding and generated mods are unchanged.

## Notes

- If you pinned `HD2RuntimeGUI.exe` to the taskbar or Start, or made a shortcut to it, pin `HD2RuntimeModBuilder.exe` again after updating.
- Windows SmartScreen may ask again on the first start of `HD2RuntimeModBuilder.exe` because the executable is new and unsigned.
