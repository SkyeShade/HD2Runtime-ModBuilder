# HD2Runtime ModBuilder 1.1.1

A small UI patch: **no more acknowledgement checkboxes**.

**Download:** `HD2Runtime-ModBuilder-v1.1.1-win-x64.zip` (Windows 10/11 x64). Extract it and run **`HD2RuntimeModBuilder.exe`**, or use **Install update** from 1.0.0, 1.0.1 or 1.1.0.

## Changes
- Shared, unverified-effect and replacement risks are now **warnings only**. You no longer tick "I understand this affects other users of this object", "I understand this effect is not gameplay-confirmed" or "I understand this replacement may not load correctly" before building.
- The generated Lua always carries the opt-in flag HD2Runtime requires for each write (`allow_shared`, `allow_unverified_effect`, `allow_unverified_reference`), exactly as an acknowledged edit did in 1.1.0.
- This applies to every editor: player weapons, composition (projectiles, damage, explosions, terminal actions), support weapons, stratagems, vehicles and mounted weapons, backpacks, magazine attachments, boosters and drop pods.
- The weapon header and Changes page no longer count "acknowledgements required".

## Unchanged
- Projects that were waiting on an acknowledgement now build without further action. Their saved edits and generated Lua are otherwise unchanged.
- Real review items still apply: after rebinding to a newer SDK, a changed capability, ownership or base value must still be reviewed, and out-of-range values or unpublished changes are still refused.
- Your projects, exports, SDK cache, imported game icons and settings stay in `%LOCALAPPDATA%\HD2RuntimeGUI\`. The project file format is unchanged.
