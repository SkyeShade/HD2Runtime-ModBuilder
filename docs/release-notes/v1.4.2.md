# HD2Runtime ModBuilder 1.4.2

Support for **HD2Runtime 0.28.1**, a much faster **Changes** page for large projects, and clearer **armory labels**.

**Download:** `HD2Runtime-ModBuilder-v1.4.2-win-x64.zip` (Windows 10/11 x64). Extract it and run **`HD2RuntimeModBuilder.exe`**, or use **Install update** from any earlier version.

**New projects require [HD2Runtime 0.28.1](https://github.com/SkyeShade/HD2Runtime/releases/tag/v0.28.1).** Projects bound to an older SDK keep requiring that SDK's Runtime until you rebind them.

## HD2Runtime 0.28.1
- ModBuilder 1.4.2 ships the HD2Runtime 0.28.1 SDK and uses it for new projects, offline too. Every SDK file it reads is byte-identical to the one in the public 0.28.1 release. The capabilities are the same as 0.28.0's; code completion for custom Lua adds `hd2.diagnostics.operations()`.
- **Your projects keep their SDK.** Updating ModBuilder never changes the SDK a project is bound to, and never rewrites the project. Its export keeps declaring that SDK, which HD2Runtime 0.28.1 reads: an SDK 0.27 project's edits that HD2Runtime 0.28.0 refused for a missing `allow_unverified_effect` (the PLAS-101 Purifier's explosion damage, for example) apply again on 0.28.1, where they are logged as legacy operations.
- **Rebinding** a project to SDK 0.28.1 (Settings) keeps its edits, writes the acknowledgements the 0.28 SDKs require, and exports a mod that requires 0.28.1. A project bound to SDK 0.28.0 generates the same operations after rebinding.

## Performance
- The Changes page opens and responds much faster in large projects. With 600 changes, opening the page drops from about 5 s to under 0.1 s, switching one edit off or on from about 4 s to under 0.1 s, and **Show all fields** in a weapon group from about 12 s to instant.
- A change group builds its fields and editors when you expand it, not while it is collapsed.
- Each edit does less work: a value committed again unchanged is not saved and rebuilt again, and the checks behind the Lua preview run once per edit instead of twice.
- This is ModBuilder's own speed. How long HD2Runtime takes to apply a mod's changes in game is unchanged: every change is still its own Runtime operation, so one refused change never stops the others.

## Armory labels
- Support weapons: the trait list from the Helldivers wiki is now labelled **Wiki: …** and shown in full (it was cut to three). The labels the game's armory shows are under **Armory labels**, read from the weapon itself; the two can differ (the M-1000 Maxigun's own record lists none).
- A weapon that shows several penetration labels (SG-20 Halt, LAS-17 Double-Edge Sickle, P-33 Missile Pistol) no longer reads "No penetration label"; the reason from HD2Runtime is shown.
- The two **INCENDIARY** labels are told apart in the Add trait list by their IDs.

## Unchanged
- The project format is unchanged, and so are the operations generated for a project on its own SDK.
