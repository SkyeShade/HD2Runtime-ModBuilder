# HD2Runtime ModBuilder 1.1.2

A small UI cleanup for stratagem **mission uses**.

**Download:** `HD2Runtime-ModBuilder-v1.1.2-win-x64.zip` (Windows 10/11 x64). Extract it and run **`HD2RuntimeModBuilder.exe`**, or use **Install update** from 1.0.0, 1.0.1, 1.1.0 or 1.1.1.

## Changes
- **Compact mission-use control.** The separate Unlimited / Limited radio buttons are replaced by one dropdown in the same column as Cooldown: `[ Unlimited ▼ ]`, or `[ Limited ▼ ] [ 3 ]`. The count box appears only when Limited is selected.
- The dropdown offers only the modes the bound SDK allows for that stratagem, and the count can be changed only where HD2Runtime allows it. Switching from Unlimited back to Limited suggests the original count.
- The mission-host / HUD caveat is now a small ⓘ next to "Mission uses" (hover for the text, also in the field's ⓘ details) instead of a full-width paragraph. The **Gameplay-proven** badge moved next to **Modified**.
- Field rows now keep their value column aligned whether or not they show **On** / **Reset field**, so edited and unedited rows line up in every editor.

## Unchanged
- Unlimited is still written as HD2Runtime's own `'unlimited'` token, never a large number. Generated Lua, Changes, Lua Preview, Build / Export and reset behave exactly as in 1.1.1.
- Eagles keep their uses-per-rearm setting and have no mission-use control.
- Changes that are not gameplay-confirmed still carry `allow_unverified_effect` and show a warning.
