# HD2Runtime ModBuilder 1.0.0

The first public release of **HD2Runtime ModBuilder**, a visual mod-authoring app for [HD2Runtime](https://github.com/SkyeShade/HD2Runtime). You choose what to change in Helldivers 2's gameplay data and review every edit. ModBuilder generates guarded HD2Runtime Lua and builds a mod-manager-ready ZIP, with no Lua or memory-layout knowledge needed.

**Download:** `HD2Runtime-ModBuilder-v1.0.0-win-x64.zip` (Windows 10/11 x64). Extract it anywhere you can write to and run `HD2RuntimeGUI.exe`. Requires the Microsoft Edge WebView2 Runtime; .NET is included. Mods built with ModBuilder need HD2Runtime installed.

## Highlights

### Projects and workspace
- A project library with create, open, rename, duplicate and remove. Every project has a stable resource ID and mod-manager GUID.
- A compact project Overview: author, version, change count, SDK binding, build/export, and project details.
- Changes are saved automatically as you edit.

### Player Weapons
- All 80 published player weapons, with search and filters for slot, category, family, editable and shared fields.
- Grouped, compact field editing: fire rate and fire modes, ammo and magazines, handling, heat and heatsinks, projectiles, damage, explosions and composition. Each field shows its base value, your value, and a reset.
- Magazine attachments are edited where HD2Runtime publishes that they own the magazine.

### Stratagems
- **Support:** support weapons, **vehicles** and **backpacks** in one place, with Support Weapons, Vehicles, Backpacks and Other / Standalone tabs. A vehicle or backpack stratagem opens one editor for its call-in and the vehicle or backpack it delivers.
- **Offensive:** orbitals and Eagles, including per-stratagem cooldowns and the shared Eagle rearm system.
- **Defensive:** sentries, emplacements, mines and the Shield Generator Relay, from the stratagem to its deployed entity, mounted weapon and attacks.
- Everything is driven by HD2Runtime's published stratagem catalog; nothing is guessed from names.

### Boosters
- All 20 published boosters with their writable values, relationships and Runtime's blockers.

### Review and build
- **Changes** lists every edit, grouped by what it affects, with enable/disable, notes and reset.
- **Lua Preview** shows the exact guarded Runtime Lua that goes into the mod: `hd2.patch`, `hd2.transaction`, `hd2.plan` and `hd2.ensure`, each with expected base values.
- **Build / Export** writes a verified, deterministic mod ZIP with its HD2Runtime and Bingus dependencies declared.
- **Guarded acknowledgements:** writes to shared definitions or effects HD2Runtime has not proven must be acknowledged explicitly before a build.
- **In-game Mod Options** (optional, HD2Runtime SDK 0.25+): expose edited values as sliders and choices, with a master toggle, in the game's MODS menu.

### HD2Runtime SDK binding
- Ships with the verified HD2Runtime 0.25.1 SDK metadata and works offline.
- Checks HD2Runtime releases for newer SDKs, validates downloads, and keeps every installed SDK version.
- Projects stay bound to their SDK until you rebind. Changed fields are flagged for review, never silently rewritten.

### Your own game icons
- Stratagem and booster icons are imported from your local Helldivers 2 installation, automatically when it is found, and stored on your PC. They are matched through HD2Runtime's published icon identities. No game artwork is distributed.

### New identity
- New HD2Runtime ModBuilder branding: the reticle icon on the executable, window, taskbar and Alt-Tab, and the full lockup in the app.
- The repository is now [SkyeShade/HD2Runtime-ModBuilder](https://github.com/SkyeShade/HD2Runtime-ModBuilder).

### Automatic application updates
- ModBuilder checks this repository's releases once when it starts. When a newer version exists, a banner offers **Install update**. The update is downloaded, its SHA-256 checked, and installed by a small updater that restarts the app. If anything fails, the current version is kept.
- **Settings → Application updates** shows the current and latest versions and has **Check for updates**. It is separate from HD2Runtime SDK updates.

## Upgrading from HD2RuntimeGUI 0.x

Replace the old folder with this release, or extract it to a new folder. Your projects, SDK cache, imported icons and settings stay in `%LOCALAPPDATA%\HD2RuntimeGUI\` and are picked up unchanged; no migration is needed. The executable keeps the name `HD2RuntimeGUI.exe` for compatibility.

## Notes

- The executable is not code-signed yet, so Windows SmartScreen may warn on first launch.
- ModBuilder does not launch the game, deploy mods or access game processes.
